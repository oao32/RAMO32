# 🏋️‍♂️ OAO - OWN AURA OUTCOME Training Portal
### منصة التدريب الرياضي المتكامل الفاخر - إشراف الكوتش عمر عدنان

---

## 📌 نبذة عن المشروع (Project Overview)
**OAO (OWN AURA OUTCOME)** هي منصة رياضية رقمية متكاملة مصممة بأعلى معايير الفخامة والاحترافية لدعم المتدربين والرياضيين. تجمع المنصة بين:
- بوابة المشتركين (رياضيو الباقة القياسية Standard ورياضيو الباقة البلاتينية VIP).
- لوحة تحكم الكوتش عمر عدنان لإدارة المشتركين، جداول التمارين، الأنظمة الغذائية، واستفسارات المتدربين.
- نظام إقرار قانوني وعقد اشتراك إلكتروني موثق برقم توثيق رسمي وتوقيع رقمي مطابق.

---

## 🚀 المميزات الرئيسية (Key Features)

### 1. الأنظمة الغذائية الرياضية المعتمدة (Dedicated Diet Plans)
- ملف مستقل ومنظم بالكامل: `src/data/nutrition/dietPlanData.ts`.
- **الباقة القياسية (Standard Diet)**: 7 خيارات فطور + 7 غداء + 7 عشاء + 6 سناكات.
- **الباقة البلاتينية (VIP Platinum Diet)**: 7 خيارات فطور VIP + 7 غداء VIP + 7 عشاء VIP + 6 سناكات VIP (مع توقيت الوجبات، المكملات، ومصادر بروتين نقية).
- سهولة التعديل المباشر من قبل المدرب دون الحاجة للمساس بأكواد الواجهة.

### 2. رموز الاشتراك والدخول السري (Passcode System)
- **دخول المشتركين**: إدخال رمز الاشتراك المخصص (مثل `RAMO32` للباقة البلاتينية أو `OAO-101` للباقة القياسية).
- **دخول الكوتش**: رمز الكوتش السري المعتمد `RAMO3223`.
- حقول إدخال نظيفة بدون نصوص افتراضية أو مساعدة مكشوفة.

### 3. بنود الإقرار وإخلاء المسؤولية الرقمي
- إقرار قانوني إلزامي مقسم إلى 4 بنود واضحة:
  1. الحالة الصحية والمسؤولية التدريبية عن بُعد.
  2. النظام الغذائي والمكملات.
  3. الملكية الفكرية وحظر التسريب وإعادة الإنتاج.
  4. سياسة الدفع، الاسترجاع، والنتائج.
- مطابقة إلزامية 1:1 بين الاسم الثلاثي في البيانات الشخصية والتوقيع الإلكتروني المعتمد.
- لوحة رسم توقيع رقمي باللمس أو الماوس مع ختم توثيق رسمي.

### 4. بنية التخزين المحلي والربط السحابي (Offline-First & Cloud Ready)
- **الوضع المحلي الفعّال 100% (Active Local Mode)**: تعمل جميع خصائص المنصة (المشتركون، التمارين، الأنظمة الغذائية، مؤشر BMI، الاستفسارات والردود، والإقرارات) محلياً عبر `LocalStorage` بسرعة فائقة ودون الحاجة لاتصال خارجي.
- **الربط السحابي بـ Supabase (اختياري)**: إمكانية ربط قاعدة بيانات Supabase لمزامنة السجلات بين أجهزة متعددة وتتبع سجلات الذكاء الاصطناعي (`ai_generation_logs`).

## 💻 طريقة التشغيل محلياً (Getting Started)

### المتطلبات الأساسية (Prerequisites)
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التثبيت والتشغيل (Installation Steps)
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. بدء سيرفر التطوير المحلي
npm run dev
```

التطبيق سيعمل مباشرة على الرابط:
`http://localhost:3000`

## 🗄️ ضبط قاعدة البيانات (Supabase Configuration - اختياري)

إذا أردت تفعيل المزامنة السحابية عبر Supabase:
1. أنشئ مشروعاً مجانياً على [Supabase.com](https://supabase.com).
2. انسخ `Project URL` و `anon public key` من لوحة التحكم (`Project Settings > API`).
3. أدخل البيانات إما في ملف `.env`:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```
أو من داخل **لوحة تحكم الكوتش > تبويب قاعدة البيانات** مباشرة بنقرة واحدة!
4. شغّل استعلام SQL المتوفر في لوحة التحكم داخل `Supabase SQL Editor` لإنشاء الجداول وسياسات الحماية (RLS).

## 📁 هيكلية المجلدات الرئيسية (Project Structure)
```
├── src/
│   ├── components/         # المكونات المشتركة (الهيدر، الفوتر، بطاقات القياسات)
│   │   └── nutrition/      # مكون عرض النظام الغذائي الرياضي
│   ├── data/
│   │   ├── initialData.ts  # البيانات الأولية وتفاصيل التمارين
│   │   └── nutrition/      # ملف النظام الغذائي المعتمد (dietPlanData.ts)
│   ├── lib/
│   │   └── supabase.ts     # دوال الاتصال والتحقق والمزامنة وقوالب SQL
│   ├── pages/
│   │   ├── HomePage.tsx    # الصفحة الرئيسية الرسمية لشعار وهوية OAO
│   │   ├── SubscribePage.tsx # صفحة الباقات والاشتراك
│   │   ├── StandaloneSubscribePage.tsx # صفحة العقد والإقرار المستقلة
│   │   ├── admin/          # لوحة تحكم الكوتش عمر عدنان
│   │   └── user/           # لوحات تحكم المشتركين (Standard & VIP)
│   └── types.ts            # تعريفات TypeScript للأنظمة والمشتركين
├── server.ts               # سيرفر Express مع وسيط Vite ودعم Gemini AI
├── .env.example            # مثال لمتغيرات البيئة المعتمدة
└── package.json            # الحزم والتبعيات ومكتبات المشروع
```
